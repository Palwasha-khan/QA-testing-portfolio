# QA & Testing Portfolio – Palwasha Khan

This repo contains API testing artifacts (Postman collections), manual test cases, 
and sample bug reports created while testing my own full-stack projects.

## Postman Collections
- **MDM System** – Tests authentication, and Device endpoints(compliance engine endpoints or remote 
  command endpoints), including negative test cases for invalid tokens/unauthorized access.
- **SparkCart** – Tests product, cart, and checkout endpoints, including failed 
  payment and invalid input scenarios.
- **Startup Mentor** – Tests REST API integration between React frontend and 
  Python/LLM backend.

## How to use
Import any `.json` file into Postman via *File > Import*.
